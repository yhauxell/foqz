# Foqz product & code dissection (2026-10-23, v0.13.1)

Detailed companion to the chat summary. Line references are against this worktree at commit 655755e.

## Goal of the app

A tray-first Electron desktop app that gives a knowledge worker an infinite spatial canvas (React Flow) for tasks, notes, sketches and project frames, a "mono focus" lock with a countdown timer, an AI copilot (local Ollama first, OpenAI/Gemini optional) with native canvas tools and MCP in both directions, and a GitHub issue bridge. Local-first, no accounts, no telemetry. Two open epics point at a plugin marketplace (#48) and PocketBase cloud sync (#39).

Codebase: ~28.6k lines across `src/` and `electron/`, 143 commits, 11 node types, 17 native AI tools, 5 Playwright suites + 1 vitest file.

## A. Canvas core & persistence

### Works
- Multi-board catalog in localStorage (`src/lib/storage/keys.ts:2-20`), create/switch/rename/delete wired in `TopbarBoardMenu.tsx:43-80`; `switchBoard` saves outgoing board, loads target, clears undo (`flowCanvasStore.ts:1740-1788`).
- Undo/redo via zundo over `{nodes, edges, annotations}`, limit 100 (`flowCanvasStore.ts:2114-2124`).
- 11 node types (`src/poc/nodes/index.ts:15-27`). Images pasted as base64 data URLs into node data (`FlowCanvas.tsx:385-420`).
- Project frames with drop-reparenting + confirm modal (`FlowCanvas.tsx:607-650`, `949-992`); group/ungroup (`store:1887-1945`).
- Annotations: complete model (kinds, status, threads, anchors), cascade delete (`store:1664-1670`). Most complete subsystem.
- Quick task capture → `parseQuickTaskCapture` (AI with regex fallback, `quickTaskParse.ts:155-293`).

### Half-built / inconsistent
1. **Boards never reach disk.** README claims `boards.json` in app-data; actually boards live in renderer localStorage. `snapshot:save/load` IPC (`main.cjs:736-753`), `exportBoardToFile`/`importBoardFromFile` (`preload.cjs:8-9`) and `onPrepareShutdown` (`preload.cjs:76`) have zero callers in `src/` (only `global.d.ts`). `clearBoardFile` is called (`store:1847`) but unlinks a file nothing writes.
2. **No flush on quit.** Autosave is a 600 ms debounce (`FlowCanvas.tsx:539-558`); main waits up to 8 s for a `focus:prepare-shutdown` ack that no renderer code registers (`main.cjs:1082-1098`). Last edit before quit can be lost.
3. **Corrupt snapshot = silent wipe.** `loadBoardSync` returns null on parse error → falls back to empty/seed board (`store:40-57`), then autosave overwrites the corrupted blob 600 ms later. `BOARD_SNAPSHOT_VERSION = 1` is written but never branched on (`snapshot.ts:40-43`); nodes/edges are cast, not validated.
4. **localStorage quota.** Base64 images + full `JSON.stringify` per autosave; `saveBoardSync` only `console.warn`s on quota (`LocalStorageAdapter.ts:148-156`). User keeps editing with silent non-persistence.
5. **Viewport persistence dead.** `BoardSnapshot.viewport` typed and parsed, never captured (`snapshot.ts:94`, `TopbarBoardMenu.tsx:123`).
6. **Storage adapter "phase 1" is a stub.** `setCanvasStorage` throws for anything but `LocalStorageAdapter` (`storage/index.ts:32-42`); `subscribeBoard` never implemented; store only calls `*Sync` helpers.
7. **Runway templates are labels + one number.** `capacitySlots` only draws watermarks (`RunwayFrameNode.tsx:65, 329-345`); no WIP cap in `sendTaskToRunway` (`store:572-707`); `critical_path` has no gating; `eisenhower_matrix` only changes watermark labels; `ultradian_90` is 30 min/3 slots (`canvas.ts:189-193`), contradicting README. Runway lookup string-sniffs titles containing "Runway" (`store:474-478`, `WaypointRail.tsx:70-74`).
8. **Dead code**: `WorkspaceSidebar.tsx` (343 lines, unreferenced); `@deprecated BoardEntry` + re-exported storage keys (`store:22-30`); `src/lib/focusMeta.ts` (no callers); `isToolUnsupportedError` (`mcpAgentLoop.ts:248`).
9. **Duplicated logic**: export JSON in `TopbarBoardMenu.tsx:113-134` and `FocusSettings.tsx:773-797`; reset in both; `/image` slash branch duplicated in `ElementInlineChat.tsx:1040-1049`.
10. **Shortcut cheatsheet drifts from bindings** (`shortcutsConfig.ts` vs `useFlowCanvasShortcuts.ts:60-93`): lists removed `T`/`A`, omits `b`, `s`, `l`, `shift+r`, `meta+n`, `alt+meta+n`, `alt+shift+a`; `c` listed twice.
11. **Secrets in board data**: per-project `githubToken` written to project-frame node data (`ProjectConnectorsModal.tsx:388`, `GitHubIssuesModal.tsx:360`) → localStorage, undo history, both JSON exports.
12. **Import overwrites current board in place** with no confirmation (`FocusSettings.tsx:815-818`).
13. **Delete frame = delete all children** on one Backspace (`store:1656-1661`), undo is the only recovery.
14. **Re-render fan-out**: frames, rail, panels subscribe to the whole `s.nodes` array (`ProjectFrameNode.tsx:71`, `RunwayFrameNode.tsx:71`, `WaypointRail.tsx:30`); `realignRunwayNodes` runs inside every `updateNodeData` (`store:1622-1654`).
15. Spec `reactflow-poc-spec.md` is stale (names files that don't exist).

### Missing
Durable file storage + backups; schema migrations/validation; flush-on-quit; viewport restore; due dates / recurrence (no such fields anywhere); keyboard nav between nodes; multi-select align/bulk ops; store unit tests (zero).

## B. Focus loop & done lifecycle

### Works
- Lock → 25-min timer → extend (+5/+15), pause, reset; Esc hold 3 s force-unlock.
- Done stamps `completedAt`, auto-advances runway (`store:1629-1651`).
- Sweep ticker every 30 s + mount (`useWorkdaySweepTicker.ts:66-80`), eligibility in `logbookTiming.ts`, monthly JSON via IPC (`electron/logbook.cjs:43-74`) or localStorage fallback, 10 s undo toast, restore to last position (`LogbookDrawer.tsx:88-139`), downstream dependency stubs, relation-gated AI context.

### Half-built
1. **Timer-end does nothing.** At 0 it flips `isTimerRunning=false` (`FocusCanvasApp.tsx:284-287`). `playFocusBlockEndFeedback` (notification + chime, `focusSessionFeedback.ts:23-38`) has zero callers. `notifyOnTimerEnd`/`playSoundOnTimerEnd` are settings only. Overlay shows "Session Paused" (`MonoFocusController.tsx:484`), indistinguishable from pause; task stays active and **blocks the sweep indefinitely** (`store:1404`, ticker:33).
2. **Duration settings never read.** `defaultFocusMinutes`/`durationPresets` are validated, editable, and unread by any timer. 25 min hard-coded in 4 places (`store:443-453`, `MonoFocusController.tsx:105,423`, `FocusTaskNode.tsx:359`, `ActiveNodeControlStrip.tsx:212`).
3. **Exit friction vanishes without TypeSafe.** `evaluateJev` throws on missing key (`jev.ts:88-92`); catch unlocks silently (`MonoFocusController.tsx:320-327`). `typesafeEnabled` is never read by `jev.ts`. Even when configured, a one-click "Force End Session" link bypasses it.
4. **Timer is tick-based, not wall-clock.** `backgroundThrottling` not disabled; hidden window or sleep drifts. `activeFocusNodeId`/`timerSecondsRemaining` not in snapshot → session lost on restart.
5. **Focus ticks hammer the store.** Per-second `updateNodeData` → full autosave every second and one undo entry per second (undo history gone after ~100 s of focus).
6. **No session records.** Only cumulative `focusSecondsSpent` on the node; never shown on the card; surfaces only after sweep as per-day sums in the Logbook.
7. **Logbook vs spec**: atomic tmp+rename writes claimed (README, spec §3.3) but `electron/logbook.cjs:40` is plain `fs.writeFile`; default hours 09–17 vs spec 09–18; `LogbookDay.summary` never written; `completedVia` always `"manual"` (focus/runway/agent/github never emitted); field names differ from spec.
8. **Jev/TypeSafe has no local path.** All six evaluators require the paid key. Without it: friction gone, Spotlight prioritization `alert()`s (`GlobalSpotlight.tsx:650-652`), actionability/readiness tools throw to the agent (`canvasTools.ts:1282, 1354`).

### Missing
Break/Pomodoro cycles; session stats/streaks/per-task time on card; idle detection (`powerMonitor` unused); wall-clock correction; scheduled/recurring tasks; WIP limits.

## C. AI copilot, agents, MCP

### Works
- Three streaming providers with tool calling: OpenAI-compatible (`aiProvider.ts:141-318`), Gemini (`323-491`), Ollama native tools + text-scrape fallback (`ollama.ts:266-308, 378-380`), auto-retry without tools on unsupported models (`aiProvider.ts:525-545`).
- 17 native tools all implemented (`canvasTools.ts:18-485`, executor `512-1486`).
- Agent loop: 12 steps, abort between steps/tools, repeat-call breaker, synthesis turn, tool errors fed back (`mcpAgentLoop.ts:262-561`).
- Inline chat: slash commands, checkpoint extraction/apply, diff cards, model switcher, Stop/Esc with partial output preserved.
- **Foqz as MCP server** (`FoqzMcpHost.cjs`): Streamable HTTP on 127.0.0.1:7337, 24-byte bearer token at 0600, timing-safe compare, Host/Origin guard, body cap, timeouts; Claude Code/Desktop/Cursor snippets generated in `McpHostSettings.tsx:19-44`. Well designed.
- MCP client: stdio + SSE, 10 s connect timeout, GitHub token env bridging.

### Half-built
1. **AGENT.md profiles / skills are not wired.** `agentProfiles`, `customSkills`, `activeAgentProfileId`, per-project `customAgent` are read only by settings UI and `ProjectConnectorsModal` — never by `ElementInlineChat`, `mcpAgentLoop`, `canvasContext` or `canvasSpawner`. No UI to pick an active profile. The modal's "selecting cards auto-activates this profile" text and README claims are false today.
2. **"AI Copilot Drawer" and `src/lib/mcp.ts` don't exist** (README dead references). `ElementInlineChat` in canvas scope replaced it.
3. **"GitHub MCP server built-in" is not true.** Default MCP config is empty (`mcpConfig.cjs:7-9`); GitHub is a Settings template that runs `npx -y @modelcontextprotocol/server-github` (deprecated package, needs Node on Electron's PATH) (`McpSettingsTab.tsx:44-54`).
4. **Board-scope chat is one global key** `foqz_board_ai_messages` (`ElementInlineChat.tsx:690-697`), not per board → switching boards shows the previous board's conversation.
5. **User message sent twice**: chat passes history already containing the new message, loop appends it again with context (`ElementInlineChat.tsx:1064,1252`; `mcpAgentLoop.ts:290-302`).
6. **`generate_image` declared twice** (`canvasTools.ts:174-222`); deduped for MCP host but not for the chat path → duplicate function names sent to OpenAI/Gemini.
7. **Abort not propagated to local tools** (`mcpAgentLoop.ts:50-54, 400-404`): image generation/Jev calls continue after Stop.
8. **Image generation silently falls back to Pollinations** (public URL with the prompt, `aiImageProvider.ts:96-98`); `imageProvider: 'gemini'` setting has no implementation.
9. **Default Gemini model `gemini-1.5-flash`** (`appSettings.ts:88`) is a retired family; Gemini key sent as URL query param (`aiProvider.ts:333`).
10. **No tool-result truncation, no token accounting**; `get_canvas_summary` returns entire board with full notes (`canvasContext.ts:70, 188-233`).
11. **No undo grouping for agent mutations**: `expand_task` with N subtasks = N+edges undo steps.
12. **Rules-of-hooks violation** in `ElementInlineChat.tsx:1327` (early return before hooks at 1333+).
13. **MCP host has no per-tool allow-list**; external agents get `delete_node` and `generate_image` (spends user's OpenAI key); tools missing `nodeId` fall back to current selection (`canvasTools.ts:874, 1303`).
14. **OpenRouter** only via pasted base URL; no preset.

### Risks
Plaintext secrets in `app-settings.json`, localStorage mirror (`jev.ts:75`), and node data; prompt injection from node text and external MCP results with mutating tools enabled and no confirmation; `window.focusStore.mcp.callTool` exposed generically to renderer (`preload.cjs:27`).

### Missing
Anthropic provider (0 hits); tool-permission prompts; usage/cost display; Streamable-HTTP/authenticated remote MCP client; retry/backoff; cross-node memory.

## D. Integrations, shell, distribution, QA

### GitHub
- Two-way sync covers exactly: state, priority↔labels, one assignee (`githubReconcile.ts:12-14`, `githubTaskSync.ts:29-37`). Title/body one-way at import/create. Real three-way merge with conflict resolver (`githubTaskSync.ts:80-98, 315-342`) — solid.
- Push debounced 1.5 s, pull every 10 min (settable). **No 403/429/Retry-After handling** anywhere.
- Classic PAT only, no OAuth/device flow; PRs display-only via deprecated `mockingbird-preview`; no webhooks; issue list capped at 50.
- **Notion and Sentry connectors are placeholders**: `ProjectConnectors.notionWorkspace/sentryProject` are set/displayed in the modal and read by nothing. README promises them.

### Electron shell
- `contextIsolation:true`, `nodeIntegration:false`, but `sandbox:false` (`main.cjs:639-641`); **no CSP**; `onHeadersReceived` only strips Origin/Referer for `api.typesafe.ai` (`main.cjs:1216-1236`). External links handled correctly. `fetchOgMetadata` is an unrestricted fetch with spoofed UA (`main.cjs:907-963`).
- Tray toggle, hide-on-blur unless pinned, always-on-top default, global `Cmd+Shift+F` with fallback, open-at-login only packaged.
- Windows/Linux: `frame:false, transparent:true`, no `skipTaskbar` → still occupies taskbar; Linux tray not guarded.
- **Auto-update cannot work on macOS**: builds unsigned (`CSC_IDENTITY_AUTO_DISCOVERY:false` in both workflows); `electron-updater` refuses unsigned installs. Entitlements enable JIT/unsigned memory/disable library validation.

### Distribution
- release-please → publish matrix (`release-please.yml:27-62`). **No CI job runs tsc, vitest or Playwright.**
- `install-latest-mac.sh` only matches `*-arm64-mac.zip` (README promises Universal), `rm -rf`s the app and strips quarantine via curl-pipe-bash.
- Landing page claims are modest and accurate; README overclaims (Notion/Sentry, Copilot Drawer, GitHub MCP built-in, boards.json, atomic logbook writes, OpenRouter, AGENT.md auto-activation).

### QA
- 1 vitest file (12 cases, `LocalStorageAdapter.test.ts`); Playwright: canvas (17), annotations (4), logbook (4), GitHub sync (6, faked API), Electron smoke+MCP (2).
- Untested: store, `githubReconcile.ts` (pure, easy win), `main.cjs` settings merge/updater/tray, MCP client manager, `aiConnectors.ts`. `ErrorBoundary` just `console.error`s.
- `npx tsc --noEmit -p tsconfig.app.json` → **22 errors** (7 environmental in this worktree: missing `vitest`/`@types/node` in node_modules; ~15 real: `useFlowCanvasShortcuts.ts:81-82` undefined `onCommentTool`, `FocusTaskNode.tsx:1154,1208,1219`, `FocusSettings.tsx:1375-1377`, `useWorkdaySweepTicker.ts:28`, `SemanticEdge.tsx:106`, `LogbookDrawer.tsx`, `ActiveNodeControlStrip.tsx`, `NodeUpdateActionCard.tsx`). Vite build doesn't type-check, which is how this ships. `vitest` could not start in this worktree (needs install).

### Missing for real users
Crash reporting; first-run/onboarding (seeds a demo board pointing at `yhauxell/foqz`, `store:60-72`); schema versioning; automatic backups; `safeStorage` for secrets; i18n (0); accessibility beyond a handful of aria-labels; CI quality gate.
